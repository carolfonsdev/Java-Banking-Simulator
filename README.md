# 🏦 Java Banking Simulator

A simple command-line banking application built with Java as part of Alura's Java course.

## 📋 About

This project simulates basic banking operations through an interactive terminal menu. The user can check their balance, transfer funds, and receive deposits in a loop until they choose to exit.

## ✨ Features

- View current account balance
- Transfer funds (with insufficient balance validation)
- Receive deposits
- Interactive menu loop with input validation

## 🚀 How to Run

**Prerequisites:** Java JDK 8 or higher
```bash
# Clone the repository
git clone https://github.com/your-username/your-repo-name.git

# Navigate to the project folder
cd your-repo-name

# Compile
javac Desafio.java

# Run
java Desafio
```

## 🛠️ Technologies

- Java
- Scanner (user input)
- Text Blocks (Java 13+)

Project developed during the **Java course on [Alura](https://www.alura.com.br/)**, focused on practicing control flow, user input handling, and basic data manipulation.
